## 使用说明：
* ### 在打败精英怪物后，进行块部件奖励的二选一时，所获得的不再是一整个块，而是获得块部件所包含的单部件
* 例如一个由四个炸弹部件组成的块部件，会直接获得四个炸弹部件
* 这在一定程度上降低了游戏难度，不过也在很大程度上降低了游戏乐趣，毕竟在这个游戏中想法设法的摆放块部件以获得最佳效果是游戏的核心玩法
* 目前只检测了战斗奖励所获得的块部件，经由商店和剧情所获得的块部件还是只会获得一个块不会进行拆分
<br/>

## Instructions for Use:
* ### After defeating an elite monster, when choosing between two "Group" rewards, you will no longer receive an entire "Group". Instead, you will receive the "Single" contained within the "Group".
* For example, a "Group" composed of four bomb parts will directly grant four bomb parts.
* This reduces the game difficulty to some extent, but it also significantly diminishes the fun, as figuring out how to arrange "Group" for optimal effect is a core gameplay element.
* Currently, only groups obtained as battle rewards are affected. Groups obtained from shops or story events will still be received as a group and will not be split.
<br/>

## 使用方法：
* ### エリート敵を倒した後、塊パーツ報酬を二択する際、得られるのは塊パーツ全体ではなく、その塊パーツを構成する単パーツとなります。
* 例：爆弾パーツ4つで構成される塊パーツの場合、爆弾パーツを4つ直接入手します。
* これはある程度ゲームの難易度を下げますが、このゲームの核心的な楽しみである「塊パーツをどう配置するか考え、最適な効果を得る」という部分を大きく減らしてしまうことにもなります。
* 現在は戦闘報酬で獲得する塊パーツのみが対象です。ショップやストーリーで獲得する塊パーツは、依然として1つの塊として獲得され、分解されません。
